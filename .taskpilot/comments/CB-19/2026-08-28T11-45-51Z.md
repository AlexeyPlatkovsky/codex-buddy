Compatibility decision: ConnectorSnapshot now belongs to codex-mcp and exposes connector IDs as strings. The temporary codex_plugin snapshot API and its plugin-specific convenience constructors are removed; codex_connectors preserves the type names but not the prior AppConnectorId return type. Retaining that type would recreate the codex-mcp -> codex-plugin edge. This is accepted as an internal fork migration break and should be included in migration notes.
